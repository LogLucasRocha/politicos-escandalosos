Sobre este mapa

Este mapa reúne políticos e outras figuras públicas que estiveram envolvidos em atos repugnáveis — corrupção, fraude, abuso de poder, entre outros — e as pessoas que os apoiam ou apoiaram.

Estar no mesmo partido não significa, necessariamente, ter uma ligação direta. Cada pessoa mapeada aqui tem um motivo específico para estar no grafo — passe o mouse ou clique em qualquer nó para ver qual é.

Pessoas por partido

Como usar

  • seta = relação (veja o rótulo)
  • Tamanho do nó = nº de relações
  • Clique num partido para filtrar
  • Passe o mouse num nó para ver a descrição
  • Clique num nó para ver a árvore de relações
  • Duplo clique num nó para editar
  • Arraste os nós para reorganizar
  • Clique numa aresta para removê-la

Adicionar relação
